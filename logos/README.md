## Usage Guidelines

### Primary Logo (Dark Background)
- **Use for:** Website headers, dark presentations, branded materials
- **Background:** Charcoal (#1C1C1C) or darker
- **Minimum size:** 120px wide

### Secondary Logo (Light/Transparent Background)
- **Use for:** Documents, light backgrounds, print materials
- **Background:** White, off-white, or light colors
- **Minimum size:** 120px wide

### Icon Only
- **Use for:** App icons, social media profile pictures, favicons
- **Can be used on any background
- **Minimum size:** 32px

## Color Reference

| Color | Hex | Usage |
|-------|-----|-------|
| Charcoal Black | #1C1C1C | Primary backgrounds, "BlackRock" text |
| Copper | #B87333 | "AI" text, rock vein accent |
| Off-White | #F5F5F5 | Light backgrounds |
| Warm White | #EDEDED | Body text on dark |

## Clear Space

Maintain clear space around the logo equal to the height of the "AI" text on all sides.

## Don'ts

- Don't stretch or distort the logo
- Don't change the colors
- Don't add effects (shadows, gradients, outlines)
- Don't place on busy backgrounds without sufficient contrast
- Don't rotate the logo
- Don't separate the icon from the wordmark in the horizontal lockup

## File Formats Needed

For production use, you'll want to export these as:
- **SVG** — For web, scalable
- **PNG** — For digital, with transparency
- **PDF** — For print
- **ICO** — For favicon (16x16, 32x32, 48x48)
